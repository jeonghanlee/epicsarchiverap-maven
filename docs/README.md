# Documentation for the EPICS Archiver Appliance

- `book/`: the manual, an mdBook that `.github/workflows/pages.yml` builds and publishes to GitHub Pages on every push that changes it.
- `design-*.md`: design notes of components in progress.
- `milestone-daff1b7.md` and `CLOSED_DOORS.md`: the work register and the examined candidates left unchanged.
- `EPICSEvent.proto`: the protocol buffer schema of the stored samples.
