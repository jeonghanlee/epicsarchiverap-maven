About the data and the M1 boundary

This offline mockup uses eight saved synthetic signal families. Values, units, acquisition axes, and frame timestamps come from the linked source JSON files. Signal identifiers name dataset columns; they are not installed facility PV names. No appliance is connected.

Histograms, correlations, summary statistics, and amplitude spectra are calculated from the selected samples. A spectrum requires complete uniform time samples. Camera profiles use the selected saved image. Controls marked Preview remain proposals. This does not implement or accept any production milestone; M1 foundation exposes only Trend.
