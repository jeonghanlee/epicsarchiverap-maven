    Maintenance

    These change the PV or its data. Each pauses the PV first and says again what it does before it asks.

    Copies the settings and the data to a new name. Both names stay paused until you resume the new one and stop the old one.
    Converts the stored data of every store to the new type, in place. It cannot be undone, so it asks for a confirmation that a backup exists.
    Moves the data of the earlier stores up to the store you choose, so that one store holds it.

    Stop archiving

    The PV is paused and then removed from the archiver. Stored data stays unless you also delete it.
